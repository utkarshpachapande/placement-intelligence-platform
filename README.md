# Placement Intelligence Platform (PIP)

An AI-powered Placement Intelligence Platform that helps students prepare for campus placements using:

- Historical Placement Analytics
- Company Visit Prediction
- Resume Analyzer
- Skill Gap Detection
- Recommendation Engine
- AI Career Assistant (RAG)
- Placement Readiness Prediction

## Tech Stack

Frontend:
- React
- TypeScript
- Tailwind CSS
- shadcn/ui

Backend:
- FastAPI
- PostgreSQL
- SQLAlchemy

AI:
- LangChain
- ChromaDB
- Sentence Transformers
- Ollama/OpenAI

ML:
- XGBoost
- Scikit-learn
- SHAP

Deployment:
- Docker
- GitHub Actions
- Vercel
- Railway
